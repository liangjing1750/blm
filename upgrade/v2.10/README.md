# v2.10 升级说明

## 升级步骤

无需迁移脚本，替换代码重启即可。

## 核心变更

### 协作安全增强

- **Seq 持久化**：文档版本号写入历史快照元数据（`.snapshot.json`），服务重启不归零；旧快照无 seq 时按时间顺序自动推算
- **BaseSeq 磁盘查找**：内存未命中时从磁盘历史快照加载 base 文档，永远不走 2-way combine 降级，避免旧覆盖新
- **提交记录管理**：新增 `/api/collab/submits/list` 和 `/load` 端点；历史记录双 tab —— 远端历史记录 + 本地提交记录（草稿找回）
- **变更摘要**：`_diff_summary` 自动生成可读中文变更摘要，如"修改了作者、日期，新增 3 个角色"

### 目录结构调整

`manifest.json` 和 `.md` 统一放入 `manifest/` 子目录。旧格式自动兼容读取，下次保存自动迁移。

### 文档比对增强

版本下拉框支持远端历史记录和本地提交记录，来源按 `<optgroup>` 分组展示。可跨来源比对（如远端历史 vs 本地提交）。

### 冲突裁决改进

冲突对话框新增逐项"保留此项"按钮和三态按钮组（全部保留我的 / 按选择合并 / 全部使用服务端），`_setByPath` 实现逐字段混并。

### 反馈建议

工具栏新增"反馈建议"入口，独立于项目文档（`.user_ask` 文档），支持四类反馈（需求功能 / 体验改进 / 轻微缺陷 / 严重问题）和四态流转（待处理 / 处理中 / 已解决 / 已关闭）。

### 任务定义

- 参数支持列表类型（`children` 子字段），递归 clone 兼容历史数据
- 新建任务定义直接打开完整编辑器，可立即配置调用契约，无需先保存
- 新建/编辑合并为一套界面，判断 `_isNew` 控制按钮

### 流程操作

- **迁移至其它阶段**：阶段视图右键流程 → 三级联下拉（价值流环节 → 业务域 → 阶段），当前归属用蓝色圆角标签标记
- **复制流程增强**：清理无效 stageFlowRef、阶段视图复制后原地刷新不跳转、流程视图移除重复按钮
- **拖曳分组**：阶段视图拖曳流程到分组框松手即更新 `flowGroup`

### 实体操作

- **复制实体增强**：复制关系连线（relations）、构件归属（businessConstructUids），兼容新旧字段名
- **关系图空白处取消选中**：点击实体节点之外区域清除选中

### 侧边栏

- 实体列表不再折叠隐藏
- 任务定义点击跳转 + 跨 tab 自动切到业务域
- "任务定义"改名"任务"

### 使用手册

新增"服务端文件夹说明"和"多人协作合并比对"两个章节。
