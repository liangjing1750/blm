## v2.10 升级说明

### 增加复制功能

- **支持流程复制**：入口有2处：目录区右键选择某个流程、阶段视图右键选择某个流程
- **支持实体复制**：入口有2处：关系图右键选择某个实体、“打开编辑”的上方
- **支持表单自动生成关联实体的字段**：表单分组关联实体后，会把实体已定义的字段填充到表单。

### 流程操作丰富

- **迁移至其它阶段**：阶段视图右键流程 → 三级联下拉（价值流环节 → 业务域 → 阶段），当前归属用蓝色圆角标签标记
- **拖曳分组**：阶段视图拖曳流程到分组框松手即更新 `flowGroup`

### 操作体验优化
- **目录区任务跳转丰富**：点击跳转自动切到业务域
- **实体关系图空白处取消选中**：点击实体节点之外区域清除选中
- **任务定义的新建/编辑合并为一套界面**：新建任务定义直接打开完整编辑器，可立即配置调用契约，无需先保存
- **反馈建议功能增加截图和附件上传**：支持上传截图和对话盖楼，支持四类反馈（需求功能 / 体验改进 / 轻微缺陷 / 严重问题）和四态流转（待处理 / 处理中 / 已解决 / 已关闭）。
- **使用手册丰富内容**：新增"服务端文件夹说明"和"多人协作合并比对"两个章节。
