    依据/MVP：原型操作属于展示/导出能力。

## 修改、删除、统计与查询

96. 问题：交易所是否可修改未发布任务？
    决策：可以。
    依据/MVP：原型和业务规则允许未发布修改。

97. 问题：交易所是否可修改待检查任务？
    决策：MVP允许交易所直接创建的待检查记录修改。
    依据/MVP：原型 showModify 包含 pending。

98. 问题：第三方派生记录是否允许交易所修改？
    决策：MVP不允许直接修改执行内容。
    依据/MVP：第三方上报内容由第三方填写，交易所通过查阅闭环。

99. 问题：交易所是否可删除未发布任务？
    决策：可以。
    依据/MVP：原型有删除按钮。

100. 问题：交易所是否可删除待检查任务？
     决策：MVP允许交易所直接创建且尚未上报的记录删除。
     依据/MVP：原型 showDelete 覆盖 pending。

101. 问题：删除按品种任务是否返还派生记录次数？
     决策：MVP不处理已派生记录删除返还。
     依据/MVP：次数占用不返还。

102. 问题：查库统计是否独立流程？
     决策：保留独立查询任务。
     依据/MVP：现有流程有“查库统计”但细节为空。

103. 问题：统计是否需要复杂指标口径？
     决策：MVP不展开复杂指标。
     依据/MVP：先建查询维度和基础统计。

104. 问题：统计维度有哪些？
     决策：按线上/线下、查库主体、查库范围、品种、仓库、检查单位、状态、结论统计。
     依据/MVP：均来自列表筛选字段。

105. 问题：第三方承接情况是否进入统计？
     决策：进入基础统计。
     依据/MVP：有查看任务承接情况流程。

106. 问题：按品种任务完成率是否统计？
     决策：MVP统计最高次数、已查次数、剩余次数。
     依据/MVP：按品种任务的核心管理指标。

107. 问题：仓库被查次数是否统计？
     决策：MVP支持按仓库聚合。
     依据/MVP：按仓库记录有仓库字段。

108. 问题：品种被查次数是否统计？
     决策：MVP支持按品种聚合。
     依据/MVP：所有查库记录都有品种字段。

109. 问题：异常率是否统计？
     决策：MVP可由不符合要求占比计算，不单独建实体。
     依据/MVP：结果枚举足以支撑基础统计。

110. 问题：操作记录是否独立实体？

## 最终建模取向

本次提交到 BLM 文档时，按以下结构落地：

- 组件：仓库查库监管【内置领域服务】。
- 构件：查库模板管理、线上查库管理、按品种查库任务管理、按仓库查库记录管理、查库结果与确认、查库统计查询。
- 实体：仓库查库模板、查库模板明细、线上查库记录、线上查库仓单明细、按品种查库任务、按仓库查库记录、查库结果明细、查库任务承接记录、仓库确认记录、监管函关联记录、查库统计视图。
- 任务定义：围绕模板、线上查库、按品种任务、按仓库记录、承接、上报、确认、查阅、统计补齐。
- 规则：记录来源边界、额度扣减、承接锁定、统一仓库确认、查阅关联监管函、MVP异常边界。
