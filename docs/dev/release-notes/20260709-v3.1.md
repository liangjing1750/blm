# v3.1 更新说明

> 发布日期：2026-07-09

## 配置与版本

### 配置集中化：`.env`

`.agent_env` 更名为 `.env`，新增 `BLM_HOST`、`BLM_PORT`、`BLM_ADMIN_PORT`、`AGENT_URL` 四个配置项。`server.py` 的 `_load_agent_url()` 重构为通用 `_load_env(key, default)`。支持 OS 环境变量优先覆盖。`blm.py` 新增 `RuntimeConfig.host`、从 `.env` 加载。

### 版本号提取为独立文件

`version` 文件作为单一版本来源（内容 `3.1`），后端在 `/api/runtime` 接口中返回 `app_version`，前端从 API 加载显示，不再硬编码在模板中。

### 客户端版本落后检测

页面加载后每 5 分钟检测 `/api/runtime` 的 `app_version`，与初始版本不一致时右下角弹出刷新提示条，用户可关闭。

## 流程视图

### 节点/网关复制

工具条新增 `⧉ 复制` 按钮，选中节点或网关时可见。`structuredClone` 深拷贝全部内容（表单、步骤、实体操作、编排任务、业务规则），名称追加 ` 副本`，自动偏移避免重叠。边线不自动复制。

### 新增节点自动滚动

新增节点/网关后自动将水平滚动条滑到最右侧（`scrollToNewElement`），确保新元素在可视区域内。

### 阶段下拉框同步

`currentStageId()` 缓存上一次的 `processId`，检测到流程变化时自动清空 `selectedStageId`，阶段下拉框跟随当前流程。

### flowOrder 拓扑排序修复

无边线的新增节点排在最后，不再因拓扑排序被插入到既有连线节点之前，避免后续节点索引右移导致整体布局偏移。`flowOrder()` 先对有边线关联的节点拓扑排序，再按原列表顺序追加无关联节点。

### 补常用项：7 项 + 写入 name + 防重

补常用项从 3 项（前置条件、校验规则、异常处理）改为 7 项（功能描述、前置条件、后置条件、输入、输出、交互规则、非功能性需求）。规则名称直接写入 `rule.name` 而非 placeholder。已存在的规则名称跳过。每行规则增加 `+`（在下方插入）按钮。

### 表单复制粘贴增强

**Ctrl+C/V 修复：** 输入框内按 Ctrl+C/V 不再被拦截为表单级复制粘贴（检查 `target.tagName` 是否为 `INPUT`/`TEXTAREA`）。

**表单快捷操作：** 表单卡片新增 `+`（在下方插入）、`↑`（上移）、`↓`（下移）按钮。

**表单分组复制：** 分组新增 `⧉` 按钮，点击弹出 3 个选项（复制到当前表单、复制到其他表单、粘贴到当前表单）。移除分组粘贴按钮（功能合并入菜单）。

**菜单空白关闭：** 增加 `document:click` 监听，点击空白处关闭复制菜单。菜单内按钮有 `$event.stopPropagation()`。

## 阶段视图

### 流程复制

流程卡片新增 `⧉` 按钮，深拷贝流程全部内容（节点、表单、边线、网关），ID 用时间戳+随机数防碰撞，`stageFlowRef` 按 stage 去重。

### 流程迁移（取代移出）

`−`（移出）替换为 `▤`（迁移），点击弹出价值流-阶段二级下拉选择面板。选择目标阶段后执行 `removeProcessFromStage` + `addExistingProcess`，流程数据不变。

### 界面优化

- 删除顶栏"所属业务域"和"选择流程加入阶段"冗余功能
- 标题栏右侧新增操作提示文字，`margin-left: auto` 右对齐
- 迁移面板 `z-index: 1260`（与关联接口菜单一致），`grid-template-columns: 140px minmax(180px, 1fr)` 固定列宽
- 迁移面板所在节点 `overflow: visible`，避免被流程组标签遮挡
- 点击空白处关闭迁移面板
- 水平滚动条 `max-height: calc(100vh - 200px)`，固定在视口底部

## Bug 修复

### 富文本编辑器工具栏按钮失效

根因：`apply()` 中 `editor.focus()` 触发 `(focus)` → `focusAtEnd()` 销毁了用户文本选区，随后 `document.execCommand('bold')` 无选区执行无效。修复：focus 前调用 `saveSelection()` 保存选区，focus 后 `restoreSelection()` 恢复。

### 流程视图水平滚动条消失

`.process-flow-canvas-shell` 改用 flex 弹性布局替代固定 `calc(100vh - 218px)`，不再因编辑模式多出的提示条被父级 `overflow: hidden` 裁剪。

### 表单分组接口下拉框只能查一条

`formServiceOptions()` 改为返回全部接口而非仅已关联接口。多选/搜索/只看已选等下游筛选链路正常工作。
