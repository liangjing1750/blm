# 版本发布信息 20260511

## 发布范围

本版本围绕业务建模工作台的可用性、比对合并能力、预览阅读体验和建模数据结构做了一轮集中优化。

## 主要更新

### 1. 实体状态图与预览增强

- 实体状态图支持拖拽状态节点、开始节点和结束节点。
- 状态流转描述支持拖拽调整位置。
- 修复状态流转描述中文输入法输入时被打断的问题。
- 预览中增加实体状态图。
- 预览中增加角色用例图，并按角色展示对应用例关系。

### 2. 比对功能优化

- 在“复制”和“合并”之间增加“比对”能力。
- 支持选择左右两侧文档，并可选择当前版本或历史版本。
- 比对改为显式点击“开始比对”后执行，避免选择框变化时自动触发。
- 增加比对进度条，运行中禁用选择框和开始按钮，避免并发比对互相覆盖。
- 比对结果改为面向业务阅读的版本报告，不再展示 JSON 路径式差异。
- 图形坐标变化会汇总为“图形与布局变化”，不展开具体坐标。
- 比对弹窗增加明确的“关闭”按钮，避免点击遮罩误关闭。

### 3. 合并功能优化

- 合并入口按钮由“确认合并”调整为“合并前检查”，表达先检查再生成的流程。
- 合并流程调整为两步：先检查冲突项和校验问题，再生成合并文档。
- 合并校验问题增加修复向导，区分“可自动修复”和“需要人工选择”。
- 对失效规则引用、阶段连线、流程引用、角色引用、实体引用、表单实体绑定等问题提供推荐处理方式。
- 修复后会重新校验，全部通过后才能生成合并文档。

### 4. 表单与实体关联优化

- 表单与实体的关系由一对一调整为表单模块一对一关联实体。
- 一个表单可通过多个模块关联多个实体。
- 表单页面会汇总展示已关联的多个实体。
- 删除表单增加二次确认，减少误操作风险。

### 5. 使用介绍文档更新

- 更新“业务建模思考”文档结构。
- 将原有“子域、阶段、流程和流程组”的滞后内容调整为：
  - 价值流和业务域
  - 阶段和流程的区别
  - 业务组件是什么
- 原有后续章节顺延。

### 6. 界面可读性修复

- 修复“关闭”“取消”等逆向选择按钮在浅色弹窗中显示为白色、难以辨认的问题。
- 保留顶部深色工具栏中的白字按钮样式。
- 浅色界面中的逆向按钮统一改为深色文字、浅色边框和浅色悬停反馈。

## 验证情况

- Python 回归测试通过。
- 前端结构与语法检查通过。
- Playwright 端到端回归测试通过。

## 注意事项

- 本版本未改变文档存储格式的基本使用方式。
- 比对结果为只读报告，不会修改当前文档。
- 合并前检查发现冲突或校验问题时，需要先完成裁决或修复，再生成合并文档。
