# Angular 已迁功能丢失清单

更新日期：2026-06-19

## 已恢复

1. 文档属性弹窗
   - 现象：`文件 > 属性` 在 Angular 壳层退化为占位提示。
   - 旧版依据：旧版维护文档名称、作者、日期、团队空间、标签 5 个字段。
   - 恢复方式：新增 `core/document/document-properties.ts`，壳层只负责弹窗和表单绑定；保存仍写入当前文档 `meta` 并走现有同步链路。

2. 全景工作台二级入口
   - 现象：Angular 全景工作台只剩单页汇总，缺少可切换的二级入口。
   - 恢复方式：补回“全景视图 / 价值与业务域 / 业务组件”三个二级 tab，保持全景工作台内部组织，不引入旧版运行时代码。

3. 迁移状态表
   - 现象：`WORKBENCH_MIGRATION_STATUS` 仍把多个已有 Angular 组件的工作台标为 `legacy` 或 `hybrid`。
   - 恢复方式：按当前 Angular 组件入口更新为 `angular`，并增加测试防止状态表继续滞后。

4. 流程工作台帮助文案
   - 现象：流程工作台二级入口帮助仍说“只保留阶段视图和流程视图”，与当前价值流、阶段、流程、节点四个视图不一致。
   - 恢复方式：改为说明当前四个 Angular 视图和前端状态切换边界。

5. 删除、复制、归档版本
   - 现象：文件菜单中的删除、复制、归档版本退化为占位提示。
   - 旧版依据：旧版分别调用 `/api/delete/{name}`、`/api/copy`、`/api/version/create`。
   - 恢复方式：补齐 Angular `ApiService` 方法和壳层动作；复制成功后切换到副本文档，删除进入回收站，归档创建当前文档版本。

## 待继续核对

1. 预览导出
   - 当前仍是占位提示，需要单独对照旧版导出流程确认是否已迁移过。

2. 文件菜单中的比对、合并
   - 当前入口仍是占位；旧版包含较完整的版本选择、业务差异报告、合并前检查和合并应用流程，需要单独按页面级功能恢复。

3. 构件工作台中的交互契约、任务编排
   - 当前有二级入口和占位面板，是否属于“已迁后丢失”需要继续查历史提交和旧版行为。

4. 知识工作台字典管理
   - 当前保留入口但没有完整编辑模型；涉及数据模型时需要先单独确认。
