# 需求

- 比对结果恢复旧版“版本比对报告”的报表化表达。
- 默认模式为“只看差异”，只展示新增、删除、修改对象。
- 用户可以切换到“全部报告”，显示左右两侧都存在且无变化的对象。
- 用户可以再切回“只看差异”。
- 本切片不恢复旧版完整业务表格、布局差异分析和 80 条截断策略。

# 用户旅程

```gherkin
Feature: 比对报告模式

Scenario: 用户在差异报告与全部报告之间切换
  Given 用户已打开比对弹窗
  And 左右两侧文档存在一个共同未变化流程和一个差异流程
  When 用户点击“开始比对”
  Then 报告应显示“当前：只看差异”
  And 不显示共同未变化流程
  When 用户点击“全部报告”
  Then 报告应显示“当前：全部报告”
  And 显示共同未变化流程
```
