# 036 左侧目录右键复制链接

## 目标

左侧目录区的所有可定位业务元素都支持鼠标右键生成链接。链接必须以稳定 UID 为主，不依赖当前正在打开的工作台状态；打开链接后切换到正确工作台、视图并定位到目标元素。

## 覆盖范围

| 类型 | 工作台/视图 | 必要定位参数 |
| --- | --- | --- |
| 价值流 | 流程工作台 / 价值流视图 | `valueStream` |
| 阶段 | 流程工作台 / 阶段视图 | `stage` |
| 流程组 | 流程工作台 / 阶段视图 | `stage`、`group` |
| 流程 | 流程工作台 / 流程视图 | `proc` |
| 节点 | 流程工作台 / 流程视图 | `proc`、`task` |
| 业务组件 | 构件工作台 / 组件模型 | `component` |
| 构件 | 构件工作台 / 构件详情 | `component`、`construct` |
| 实体 | 构件工作台 / 实体视图 | `component`、`construct`、`entity` |
| 任务 | 构件工作台 / 任务定义 | `component`、`construct`、`task` |
| 支撑流程 | 流程工作台 / 流程视图 | `proc`，可附带 `sourceComponent`、`sourceConstruct` |
| 应用服务 | 应用工作台 / 服务视图 | `service` |
| 应用接口 | 应用工作台 / 接口详情 | `service`、`interface` |
| 应用编排 | 应用工作台 / 编排详情 | `orchestration`，可附带 `step` |
| 角色 | 全景工作台 / 角色管理 | `role` |
| 术语 | 全景工作台 / 术语管理 | `term` |
| 字典 | 全景工作台 / 字典管理 | `dictionary` |
| 字典项 | 全景工作台 / 字典管理 | `dictionary`、`item` |
| 规则 | 全景工作台 / 规则管理 | `rule` |
| 附件 | 全景工作台 / 附件管理 | `attachment`、`owner`，版本可带 `version` |

## 行为约束

1. 右键目录名称、资产按钮和支撑流程行都必须按被右键对象生成链接，不能复用当前页面对象。
2. 右键折叠箭头只负责折叠/展开，不弹出业务对象链接菜单；右键对象名称才生成对象链接。
3. UID 缺失时，允许使用兼容 ID；禁止把名称作为主要长期定位键。流程组、字典项等缺少独立 UID 时，使用父级 UID 与名称组合。
4. 打开链接后，目标不存在时保留目标工作台并提示“目标元素不存在或已删除”。
5. 链接必须保留 `doc` 参数和只读历史版本上下文。

## 验收场景

- 在不打开目标对象的前提下，右键每种目录元素，复制出的链接仍能准确打开目标。
- 重命名目标后，UID 链接仍然有效。
- 删除目标后打开旧链接，不得跳到其他同名对象。
- 阶段、流程组、节点、构件、实体、任务的链接都能自动展开目录并滚动到目标。
- 复制链接和当前视图链接使用不同菜单文案及不同参数。
