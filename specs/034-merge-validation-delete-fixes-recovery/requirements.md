# 034 合并校验删除类修复恢复 - 需求

## 需求梳理

本轮继续恢复旧版合并校验自动修复能力，范围限定为低风险“删除失效引用”类：

- `stageFlowLinks.<id>`：删除失效阶段流程连线。
- `stages.<stage>.processLinks.<link>`：删除阶段内失效流程连线。
- `relations.<id>`：删除引用不存在实体的关系。

这些修复都只作用于合并弹窗内的 `merged_document` 草稿，并调用 `/api/document/validate` 刷新校验结果，不保存工作区文档。

## 用户旅程

```gherkin
Feature: 合并校验删除类自动修复

Scenario: 用户处理删除类校验问题
  Given 合并前检查返回删除类校验项
  When 用户点击对应校验卡片中的修复按钮
  Then 系统应从合并结果草稿中删除对应失效引用
  And 系统应调用文档校验接口刷新合并分析结果
```

## 边界

- 不处理需要业务选择的规则适用对象修复。
- 不处理节点角色、实体操作、表单实体绑定等需要更细引用提取的修复。
- 不改变服务端合并算法和文档模型。
