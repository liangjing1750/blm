# 需求梳理

## 背景

旧版合并流程在完成合并前检查后，可以继续把无冲突、无校验问题的 `merged_document` 保存为工作区新文档并打开。Angular 目前只恢复了检查入口，用户还不能真正使用检查结果生成合并文档。

## 本轮范围

- 在合并弹窗中提供“生成合并文档”操作。
- 当检查结果没有冲突且没有校验问题时，保存 `merged_document` 为新工作区文档。
- 保存成功后立即打开新文档，并刷新工作区列表。

## 暂不负责

- 冲突逐项选择与 resolutions 表单。
- 调用 `/api/merge/apply` 处理已解决冲突。
- 三方合并的 base 文档选择。
