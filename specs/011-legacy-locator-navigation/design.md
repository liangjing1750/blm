# 设计

## 核心判断

新版 Angular 已经保留了旧版定位所需的主要状态字段：

- 文档：`runtime.currentFile`
- 当前工作台：`runtime.ui.mainTab`
- 流程：`runtime.ui.procId`
- 节点：`runtime.ui.taskId`
- 实体：`runtime.ui.entityId`

因此本切片不新增独立状态模型，只做两件事：

1. 复制链接时，把当前状态编码为查询参数。
2. 启动时读取查询参数，加载文档后写回 `runtime.ui`。

## 参数兼容

为兼容旧版链接，启动解析同时接受：

- 流程：`proc` 或 `procId`
- 节点：`task` 或 `taskId`
- 实体：`entity` 或 `entityId`

新版复制链接优先生成旧版短参数：`proc`、`task`、`entity`。

## 入口设计

- Shell 工具栏提供“复制链接”下拉入口，承接当前视图、流程、节点、实体的链接。
- 流程节点工作台在当前节点上下文中补充“复制节点链接”，降低用户寻找成本。
- 实体设计工作台在实体编辑上下文中补充“复制实体链接”。

## 边界

- 没有打开文档时不生成定位链接。
- URL 没有 `doc` 时不触发自动加载。
- 自动加载失败时只提示错误，不覆盖当前文档。
