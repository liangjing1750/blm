# 011 旧版定位链接恢复

## 目标

恢复旧版 BLM 的定位链接能力，让用户可以从当前文档复制可分享链接，并通过链接直接打开到指定视图、流程、节点或实体。

## 旧版证据

- 旧版 `app/app.js` 通过 `doc`、`tab`、`proc`、`task`、`entity`、`at` 等查询参数生成定位链接。
- 启动时旧版会读取查询参数，先加载文档或只读版本，再恢复流程、节点、实体等 UI 状态。
- 旧版支持当前视图、流程、节点、实体和只读版本链接。

## 本切片范围

- 支持当前文档链接复制。
- 支持流程链接复制。
- 支持节点链接复制。
- 支持实体链接复制。
- 支持通过 `?doc=...&tab=...` 启动打开文档，并恢复到对应工作台状态。
