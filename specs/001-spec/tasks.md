## 与最终目标的差距清单

- [x] 冲突提示：本地有待同步修改时收到远程快照，不能静默覆盖，需要提示“保留本地/应用远程/稍后处理”。
- [x] 自动落盘：协作会话中的最新工作稿会自动写回 `manifest.json`，且不生成普通历史快照。
- [ ] 命名版本：还没有“存为版本”，无法给评审通过稿生成稳定只读快照。
- [ ] 定位链接：还没有稳定 URL 参数跳转到流程、实体、视图、版本。
- [ ] 在线用户体验：目前只有人数提示，还没有显示谁在线、最近谁更新了什么。
- [ ] 断线重连：WebSocket 断开后尚未自动重连并按 `seq` 补齐远程变更。
- [ ] 权限与只读：还没有区分工作稿编辑、快照只读、版本只读。
- [ ] 日志体积治理：整文档快照会带来较大 JSONL，后续需要压缩、定期快照折叠或自动归档。
