# 031 合并结果预览恢复 - 需求

## 需求梳理

本轮恢复旧版“合并前检查”结果中的合并结果预览能力，属于旧版功能复刻，不新增后端数据模型。

旧版入口在合并弹窗中，用户选择左右文档并执行合并前检查后，结果区会同时展示自动合并、冲突、校验问题，以及 `merged_document` 的摘要信息。当前 Angular 已经拿到 `merged_document`，但只展示合并统计、冲突和校验列表，缺少对结果文档的可读预览。

## 用户旅程

```gherkin
Feature: 合并结果预览

Scenario: 用户完成合并前检查后查看合并结果摘要
  Given 用户已打开一个 BLM 文档
  And 工作区中存在另一个可合并文档
  When 用户打开“合并前检查”
  And 选择右侧文档并点击“合并前检查”
  Then 合并分析区应展示“合并结果预览”
  And 用户应看到合并后标题、业务域、角色数、流程数、实体数、任务数和术语数
```

## 边界

- 不改变 `/api/merge/analyze` 和 `/api/merge/apply` 数据结构。
- 不实现校验问题一键修复，本轮只恢复合并结果摘要预览。
- 不复制旧版 JS 字符串模板，只在 Angular 模板中表达同等信息。
